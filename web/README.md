# harness-web

Next.js control-plane UI for the hotel agent harness. Deployed on Vercel (not yet set up).

```bash
npm ci
npm run dev        # http://localhost:3000
npm run lint
npm run typecheck
npm run build
```

The UI reads `NEXT_PUBLIC_HARNESS_API_URL` (see the root `.env.example`). Only `NEXT_PUBLIC_*`
variables reach the browser, so never put a secret in one.

`web/AGENTS.md` is generated by Next.js; it says to read the bundled docs in
`node_modules/next/dist/docs/` before you change framework code.
